智能体在工作，Mac 就不会睡。

编程智能体工作时，Belay 让你的 Mac 保持唤醒。工作一停，Belay 就退到一边，Mac 照常进入睡眠。

工作原理

内置 Claude Code 检测，另有 Codex CLI、Gemini CLI 和 Cline 的预设。其他智能体可以指定一个工作文件夹。检测只在你的 Mac 上进行。无需注册，没有遥测。Belay 不会把你的提示词或代码发送到任何地方。
