Belay 1.3.2

  • Codex gets precise detection. Belay now reads Codex’s own turn markers, so starts and finishes are exact and retries get the same patience as Claude Code. No setup needed.
  • Two more agents are built in. Copilot CLI and OpenCode now have ready-made presets. One click to add either one.
  • Background work still counts. If a turn ends while background agents or shell jobs are still running, Belay keeps the Mac awake until they finish.
  • The network stays awake too. While Belay is holding, it also asks macOS to keep the network active, so SSH sessions and streaming replies can keep going.

Also: Belay knows you’re needed as soon as an agent asks a question, and presets now say clearly when their folder is missing.
