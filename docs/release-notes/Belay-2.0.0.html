Belay 2.0.0

  • Modules. Optional tools in Settings. Each stays off until you install it. No downloads needed.
  • Screenshot Cleaner. Automatically moves older screenshots to the Trash. You choose how long to keep them.
  • Warm Microphone. Keeps the microphone active so dictation catches your first word. No audio is recorded, stored, or sent.
  • Auto Allow. Clicks "Allow once" in Claude to approve requests for local sites. Turns off automatically after the time you set.

Auto Allow requires Accessibility access. macOS asks for microphone access when you first turn on Warm Microphone.
