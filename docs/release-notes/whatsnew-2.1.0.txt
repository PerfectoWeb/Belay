What's New – Belay 2.1.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): Auto Allow in Codex. The store build shows Nudge and Orphan Watch.

=== en ===

# Auto Allow in Codex

Clicks "Allow once" in the ChatGPT desktop app too, using the same rules for local sites. Works when Codex is enabled in Settings › Agents.

# Nudge

Plays a sound when an agent finishes, needs you, or goes quiet. Reminds you if it's still waiting. Click a notification to bring its app to the front.

# Orphan Watch

Shows processes left running after a session ends and high CPU use while an agent is idle. Never reads command lines or file contents.


=== ru ===

# Автоподтверждение в Codex

Нажимает «Allow once» и в приложении ChatGPT для Mac, по тем же правилам для локальных сайтов. Работает, когда Codex включён в Настройках › Агенты.

# Напоминание

Сообщает звуком о завершении работы, ожидании ответа или отсутствии активности. Если агент продолжает ждать, напоминает об этом. Нажмите на уведомление, чтобы перейти в его приложение.

# Присмотр за процессами

Показывает процессы, оставшиеся после завершения сессии, и высокую нагрузку на процессор, пока агент бездействует. Не читает команды запуска и содержимое файлов.
