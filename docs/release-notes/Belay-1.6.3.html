Belay 1.6.3

  • Precise Detection survives restarts and updates. Belay now keeps the same local address, so agents stay connected when the app restarts or updates.
  • Option reveals the longer choices too. In Sleep delay and the Always On timer, hold Option or Shift to show the longer durations.

Also: diagnostics now record when the local bridge starts, which port it uses, and which agent settings it updates.
