- **Modules.** Optional tools in Settings. Each stays off until you install it. No downloads needed. Removing a module clears its settings and saved folder access.

- **Screenshot Cleaner.** Automatically moves older screenshots to the Trash after a period you choose, from 1 hour to 1 week. Uses macOS metadata to identify screenshots, regardless of filename. Keeps tagged or edited screenshots by default. For existing screenshots, the retention period starts when you turn the module on.

- **Warm Microphone.** Keeps the microphone active so dictation catches your first word. Follows your macOS input selection, resumes after sleep, and can pause on battery. Audio is discarded immediately; nothing is recorded, stored, or sent.

- **Auto Allow.** Direct build only. Clicks "Allow once" in the Claude desktop app. By default, approves only requests for sites on your Mac or local network, such as `localhost`, `.local` or `.test` domains, and private IP addresses. Other requests wait for you. Keeps an approval history and can also handle requests in background sessions. Turns off after a duration you choose (4 hours by default). Requires Accessibility access.

The direct build now explains why it needs access to Desktop, Documents, and Downloads in macOS permission prompts, in all seven languages.

Modules are open to contributions: [docs/MODULES.md](https://github.com/PerfectoWeb/Belay/blob/main/docs/MODULES.md) explains the rules a module keeps and how to write one.
