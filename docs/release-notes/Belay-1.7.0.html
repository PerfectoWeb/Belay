Belay 1.7.0

  • The panel shows what agents are doing. Small badges beside each working session – shell, editing, search – straight from the agent's own hooks. Categories only, never your prompts or code.
  • Background tasks keep the hold. A turn that ends with monitors or shell jobs still running keeps your Mac awake – bounded, and the panel says so with a "bg task" badge.
  • Hooks tidy up after themselves. Belay's entries leave the agents' settings when it quits and return on launch, so a closed Belay never leaves an agent talking to a dead port.
  • Sharper returns. Closing the lid no longer eats the while-you-were-away summary, and the summary now mentions when the Mac ran hot.

Also: dark wakes no longer log as stalls, and two sessions trading turns no longer flood the diagnostics log.
