What's New — Belay 1.4.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): none.

=== en ===

# Always On, for as long as you say
Pick fifteen minutes to twelve hours under the mode picker and watch it count down. When it runs out, or the time limit pauses a hold, one click holds again.

# A quieter night screen
When the dimmer takes the display down, the screen frosts over and the countdown glows in the middle of it. Both are switches beside the dimming controls.

# The chart plays its outline
Sweep the cursor across the last fourteen days and every bar strikes a note pitched by its height.

# A steadier panel
The mode pill slides on its own, nothing jumps when the timer row appears, and a click anywhere else closes the panel.

=== zh-Hans ===

# 常开，时长由你决定
在模式选择器下方选择 15 分钟到 12 小时，看着倒计时走完。时间用尽或时间上限暂停保持时，点一下即可继续。

# 更安静的夜间屏幕
调暗器降低显示器亮度时，屏幕会蒙上磨砂效果，倒计时在中央发光。这两项都是调暗设置旁的开关。

# 图表会奏出它的轮廓
把光标划过最近十四天，每根柱子都会按自己的高度奏出一个音。

# 更稳的面板
模式胶囊自行滑动，计时器行出现时不会跳动，点击其他任意位置即可关闭面板。
