What's New — Belay 1.6.1

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): none.

=== en ===

# Set the timer by end time
Enter a duration or an end time. Belay shows the other as you type.

# Export your statistics
Before clearing your history, you can export every recorded day to CSV. Hover over the headline to see your time at the keyboard.

# A rare overnight crash is fixed
With local diagnostics enabled, the log could grow too large during a long night of agent activity and crash Belay. A detailed bug report helped track it down.
