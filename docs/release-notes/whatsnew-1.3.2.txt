What's New — Belay 1.3.2

The window's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body, '* ' lines are the small mentions at the bottom. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the window shows it.

Direct-only (never shown in the App Store build): item 3, mention 1.

=== en ===

# Codex gets built-in detection
Belay now reads Codex's own turn markers, so it knows exactly when a turn starts and ends and waits through retries just like it does with Claude Code. No setup needed.

# Two more agents are built in
Copilot CLI and OpenCode now have ready-made presets. One click each in Settings.

# Background work still counts
If a turn ends while background agents or shell jobs are still running, Belay keeps the Mac awake until they finish.

# The network stays awake too
While Belay keeps your Mac awake, it also asks macOS to keep the network active, so SSH sessions and streaming replies can keep going.

* Belay knows you're needed as soon as an agent asks a question.
* If a preset's folder doesn't exist yet, Belay says so instead of asking for access.
* The preset menu now puts the most common CLIs first.

# Да будет интернет
Belay научился просить macOS сохранять активной и сеть, чтобы SSH-сессии и потоковые ответы могли продолжаться.

* Belay понимает, что вы нужны, сразу после вопроса от агента.
* Если папки пресета ещё нет, Belay просто говорит об этом вместо запроса доступа.
* В меню пресетов самые популярные CLI теперь идут первыми.

=== zh-Hans ===

# Codex 现在支持内置检测
Belay 会读取 Codex 自己的轮次标记，因此能准确知道轮次何时开始、何时结束，并像处理 Claude Code 一样耐心等待重试。无需任何设置。

# 又有两个智能体内置了
Copilot CLI 和 OpenCode 现在都有现成的预设。在“设置”中各点一下即可添加。

# 后台工作也算在内
如果当前轮次结束时，后台智能体或 shell 任务仍在运行，Belay 会继续保持 Mac 唤醒，直到它们完成。

# 网络也会保持活跃
在 Belay 保持 Mac 唤醒期间，它也会请求 macOS 保持网络活跃，让 SSH 会话和流式回复能够继续。

* 智能体一提出问题，Belay 就知道需要你回来处理。
* 如果某个预设的文件夹还不存在，Belay 会直接说明，而不是请求访问权限。
* 预设菜单现在会把最常用的 CLI 放在前面。
