- **Copilot CLI is now built in.** Turn it on in Settings and Belay follows its sessions automatically. It reads Copilot’s own turn markers, so starts and finishes are exact. No folder setup needed.
- **Watch built-in agents wherever they work.** Using `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, or multiple profiles? Add those folders in the agent’s settings and Belay watches them too. It can even suggest nearby profiles it finds, and Precise Detection works across every folder you add. Fixes #4.
- **Your timer survives a relaunch.** An Always On timer resumes with the same time remaining after Belay restarts. If it expired while Belay was closed, the panel says so and offers Hold Again.
- **More reliable throughout.** A full reliability pass fixed dozens of issues, including a crash triggered by a local process, stalls at launch and in Settings, sessions that stayed active after their agent quit, and an awake limit that counted time while the Mac was asleep. Every fix comes with a regression test.

Also: agent tiles now show live last activity, disabled tiles dim as one piece, the About footer explains the licence more clearly (“Free & open code”), and there’s a little more polish throughout the interface.
