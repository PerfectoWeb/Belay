What's New — Belay 1.6.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): none.

=== en ===

# Copilot CLI is now built in
Turn it on in Settings and Belay watches its sessions automatically. No folders to choose.

# Watch built-in agents anywhere
Using custom config folders or multiple profiles? Add them from the agent’s settings and Belay watches them too.

# Your timer survives a relaunch
Restart Belay and an Always On timer resumes with the same time remaining.

# More reliable throughout
A broad reliability pass fixed dozens of small issues, including launch stalls and sessions that stayed active longer than they should.
