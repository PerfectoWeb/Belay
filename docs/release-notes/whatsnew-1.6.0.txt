What's New — Belay 1.6.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): none.

=== en ===

# Copilot CLI is now built in
Turn it on in Settings and Belay follows Copilot sessions on its own. Four agents, zero setup.

# Watch an agent in any folder
Custom config dirs and multi-profile setups: add every folder your agent works in, right from its tile.

# The timer survives a relaunch
An Always On timer picks up exactly where it was when Belay restarts.

# Steadier everywhere
A full audit fixed dozens of small faults, from launch stalls to sessions that overstayed their welcome.
