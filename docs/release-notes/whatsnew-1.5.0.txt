What's New — Belay 1.5.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): item 2, Precise Detection.

=== en ===

# Cline is now built in
Turn it on in Settings and Belay follows Cline sessions on its own. No folders to pick.

# Precise Detection for every agent
Claude Code, Codex, and Cline can tell Belay the exact moment work starts, finishes, or waits for you. One click in Settings.

# Agent teams in the panel
When Cline spawns teammate agents, they appear under their session, just like Claude Code subagents.

# Settings, sharpened
Each agent's detection now lives in its own tile, and every pane reads cleaner.
