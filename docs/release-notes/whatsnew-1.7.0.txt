What's New – Belay 1.7.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): "See what your agents are doing" and "Hooks clean up automatically".

=== en ===

# See what your agents are doing
Working sessions now show activity badges like shell, editing and search. Background tasks also keep your Mac awake and show why in the panel.

# Hooks clean up automatically
Belay removes its entries when it quits and restores them on launch, so agents never keep pointing at a closed Belay.

# Return summaries work better
Closing the lid no longer hides the “while you were away” summary, and it now mentions if your Mac ran hot.

=== ru ===

# Видно, чем заняты агенты

# Хуки убираются автоматически
При выходе Belay удаляет свои записи из настроек агентов и возвращает их при запуске, поэтому закрытый Belay больше не оставляет нерабочую связь.

# Сводка по возвращении стала надёжнее
Закрытие крышки больше не скрывает сводку «пока вас не было», а если Mac нагревался, Belay теперь сообщит об этом.
