What's New – Belay 2.0.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): Auto Allow.

=== en ===

# Modules

Optional tools in Settings. Each stays off until you install it. No downloads needed.

# Screenshot Cleaner

Automatically moves older screenshots to the Trash. You choose how long to keep them.

# Warm Microphone

Keeps the microphone active so dictation catches your first word. No audio is recorded, stored, or sent.

# Auto Allow

Clicks "Allow once" in Claude to approve requests for local sites. Turns off automatically after the time you set.
