Belay 2.1.0

  • Auto Allow in Codex. Clicks "Allow once" in the ChatGPT desktop app too, using the same rules for local sites. Works when Codex is enabled in Settings › Agents.
  • Nudge, a new module. Plays a sound when an agent finishes, needs you, or goes quiet, and reminds you if it's still waiting. Click a notification to bring its app to the front.
  • Orphan Watch, a new module. Shows processes left running after a session ends and high CPU use while an agent is idle. End asks a process to quit after you confirm. Never reads command lines or file contents.
  • Auto Allow returns you to your previous app after checking a background session, unless you've started using your Mac.
  • With Precise Detection on, Auto Allow no longer opens background Claude sessions unnecessarily after a turn ends.
  • Precise Detection works with ChatGPT 26.928's bundled Codex again. If setup failed after that ChatGPT update, turn Codex off and on in Settings › Agents after updating Belay.
  • Modules are easier to scan, with distinct colors, shorter summaries, and icons that animate on hover.
  • Auto Allow no longer mistakes embedded web pages in Claude or Codex for permission requests.

Auto Allow requires Accessibility access.
