Belay 1.5.0

  • Cline is now built in. Turn it on in Settings and Belay follows Cline sessions on its own. No folders to pick.
  • Precise Detection for every agent. Claude Code, Codex, and Cline can tell Belay the exact moment work starts, finishes, or waits for you. One click in Settings; Belay shows exactly what it will write before touching anything, and Remove puts it back.
  • Agent teams in the panel. When Cline spawns teammate agents, they appear under their session, just like Claude Code subagents.
  • Settings, sharpened. Each agent’s detection now lives in its own tile, and every pane reads cleaner.

Also: sessions touched by other apps’ importers no longer wake the panel, the agent switches draw honestly from the first frame, and running the test suite can no longer disturb a running Belay.
