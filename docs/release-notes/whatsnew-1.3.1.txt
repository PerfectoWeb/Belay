What's New — Belay 1.3.1

The window's text, every language in one place. '# ' starts an item's title,
the paragraph under it is the body, '* ' lines are the small mentions at the
bottom. Items must stay in the same order in every language. Edit freely,
save, then ask for a rebuild: this file gets synced into the code and the
string catalogue, and the window shows it.

Direct-only (never shown in the App Store build): item 4, mentions 1 and 3.

=== en ===

# The chart is now interactive
Hover over a day in Statistics. The bar lifts and the figures above switch to that day. Move away and the totals come back.

# Pi is built in
One click in Settings starts watching Pi's sessions. Added after a request on GitHub.

# Quiet doesn't mean finished
If an agent stops mid-answer, Belay now says it went quiet instead of calling the run finished.

# Closed-lid stops tell you why
If the time limit or heat protection ends a closed-lid hold, the notification tells you why.

* The helper status updates as soon as you approve it.
* Launch Belay mid-run and it picks the run up right away.
* Failed update checks now say why in the log.

=== zh-Hans ===

# 图表会跟随光标
将光标移到“统计”中的某一天。柱形会轻轻抬起，上方的数据也会切换到当天。移开光标后，总计数据会恢复。

如果智能体在回答途中停止，Belay 现在会将这次运行标记为“没有动静”，而不是已完成。

# 合盖保持唤醒结束时会说明原因
如果时间上限或过热保护结束了合盖保持唤醒，通知会告诉你原因。

* 批准帮助程序后，它的状态会立即更新。
* 如果在智能体工作时启动 Belay，它会立即接手监视。
* 更新检查失败时，日志现在会写明原因。
