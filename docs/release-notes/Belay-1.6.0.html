Belay 1.6.0

  • Copilot CLI is now built in. Turn it on in Settings and Belay watches its sessions automatically. No folders to choose.
  • Watch built-in agents wherever they work. If an agent uses a custom config directory such as CLAUDE_CONFIG_DIR, or you keep multiple profiles, open its settings and add the folders it uses. Precise Detection works across them too.
  • Your timer survives a relaunch. An Always On timer resumes with the same time remaining after Belay restarts.
  • More reliable throughout. A reliability pass fixed dozens of small issues, including launch stalls and sessions that stayed active longer than they should.

Also: agent tiles now show live last activity, disabled tiles dim consistently, and there’s a little more polish throughout the interface.
