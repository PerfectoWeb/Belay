Belay 1.8.0

  • See stats for each project. Double-click a session in Statistics to see agent time, sessions, tokens and recent runs for that folder.
  • Background tasks hold more reliably. Late or duplicate hook events no longer end a hold early or restart one after release.
  • Hooks recover after an interrupted quit. If Belay is killed while closing, it restores its agent settings on the next launch.
  • The diagnostics log stays small. Once it passes 3 MB, Belay trims it back to the most recent 1 MB.

Also: Sessions now keeps the latest 100 runs, and its headline shows total agent time instead of the number of rows.
