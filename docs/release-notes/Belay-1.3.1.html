Belay 1.3.1

  • The chart follows your cursor. Hover over a day in Statistics and the numbers switch to that day. Move away and the totals come back.
  • Pi is built in. One click adds Pi with the same local session watching that already worked through manual setup. Asked for on GitHub.
  • Quiet sessions stay quiet. If an agent stops mid-answer, Belay now says it went quiet instead of calling the run finished.
  • Closed-lid stops explain themselves. If the time limit or heat protection ends a closed-lid hold, the notification tells you why.

Also: the helper status updates as soon as you approve it, and failed update checks now say why in the log.
