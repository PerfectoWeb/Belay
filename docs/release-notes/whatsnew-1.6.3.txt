What's New – Belay 1.6.3

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): "Precise Detection survives restarts and updates".

=== en ===

# Precise Detection survives restarts and updates
Belay now keeps the same local address whenever possible, so agents stay connected across relaunches and updates.

# Option reveals longer choices too
Hold Option or Shift in the Sleep delay menu or Always On timer to show the longer durations.

=== ru ===

Belay теперь сохраняет прежний локальный адрес, поэтому связь с агентом не теряется после перезапуска или обновления.

# Option тоже показывает длинные интервалы
Удерживайте Option или Shift в меню «Пауза перед сном» или таймере Always On, чтобы показать более длинные интервалы.
