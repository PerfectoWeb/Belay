What's New – Belay 1.8.0

The card's text, every language in one place. '# ' starts an item's title, the paragraph under it is the body. Items must stay in the same order in every language. Edit freely, save, then ask for a rebuild: this file gets synced into the code and the string catalogue, and the card shows it.

Direct-only (never shown in the App Store build): "Background tasks hold more reliably" and "Hooks recover after an interrupted quit".

=== en ===

# See stats for each project
Double-click a session in Statistics to see that folder’s total agent time, sessions, tokens, and recent runs.

# Background tasks hold more reliably
Late or duplicate hook events no longer end a hold early or restart one after it has finished.

# Hooks recover after an interrupted quit
If Belay is killed while closing, it restores any missing hook entries on the next launch.

# The diagnostics log stays small
Once it passes 3 MB, Belay trims it back to the most recent 1 MB.

# Фоновые задачи удерживают надёжнее
Запоздалые или повторные события больше не завершают удержание раньше времени и не запускают его снова после завершения.

# Хуки восстанавливаются после сбоя при выходе
Если Belay принудительно завершится во время закрытия, недостающие записи хуков восстановятся при следующем запуске.

# Журнал диагностики остаётся небольшим
После 3 МБ Belay автоматически сокращает его до последнего 1 МБ.

=== zh-Hans ===

# 查看每个项目的统计数据
在“统计”中双击会话，即可查看该文件夹的智能体时间、会话数、token 数和最近运行。

如果 Belay 在退出过程中被强制终止，下次启动时会恢复缺失的 hook 条目。

# 诊断日志保持精简
