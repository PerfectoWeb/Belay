Belay is a menu bar utility that keeps the Mac awake while a coding agent is working. No account or sign-in is required to review the app.

Belay uses `com.apple.security.network.server` only for Precise Detection. It listens on `127.0.0.1` so Claude Code, running on the same Mac, can send local lifecycle events such as started, finished, or waiting for input. The listener uses an ephemeral port and requires a bearer token stored in Belay's own container.

This App Store build does not include `com.apple.security.network.client` and makes no outbound network connections.

To verify the listener:

1. Launch Belay and run:
   `lsof -nP -iTCP -sTCP:LISTEN -a -c Belay`

You should see Belay listening on `127.0.0.1:<port>`.

2. The port and token are stored in:
   `~/Library/Containers/com.perfectoweb.belay/Data/Library/Application Support/Belay/bridge.json`

3. Send a local event:
   `curl -i -X POST -H "Authorization: Bearer <token>" "http://127.0.0.1:<port>/hook?state=working"`

Belay returns `204`. A missing or incorrect token returns `401`.

Precise Detection is optional. Belay does not add anything to Claude Code's settings until the user enables it in Settings > Providers > Precise Detection and confirms the change shown on screen. On a fresh install, the local listener is running but idle.
