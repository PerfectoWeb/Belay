## Holding through a closed lid

Shipped in 1.3.0 for direct builds. Off by default.

Belay can keep a Mac awake while the lid is closed using a small privileged helper. The helper only holds while Belay keeps checking in, and lets go automatically when the work ends, the time limit is reached, Belay disappears, or the Mac gets too warm.

Tested on a MacBook Pro M3 Max on battery with no external display. With closed-lid holding enabled, the Mac stayed awake; without it, clamshell sleep behaved normally.

This feature is not available in the Mac App Store build because sandboxed apps cannot install the required helper.

Implementation details: [`docs/04-POWER.md`](04-POWER.md).

<br>

## Dimming the display at night

Shipped in 1.3.0. Off by default.

If Belay is keeping the display awake while you are away during the hours you choose, it can dim the screen and restore the brightness when you return.

It only applies while Belay is holding and the Mac has been idle long enough. No Accessibility permission or private API is needed, and the display returns to normal if Belay exits.

You choose the time window and dim level in Settings.

Implementation details: [`docs/04-POWER.md`](04-POWER.md).
