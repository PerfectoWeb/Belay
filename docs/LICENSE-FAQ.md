# Licence FAQ

The [licence](../LICENSE) in ten answers. The licence text wins where they
disagree; this page exists so nobody has to read it twice.

| Question | Answer |
| :--- | :--- |
| Is Belay free to use? | **Yes.** |
| Can I use it at work? | **Yes.** |
| Can my company use it internally? | **Yes**, including for commercial work. |
| Can I modify the source? | **Yes.** |
| Can I submit changes upstream? | **Yes**, please – see [CONTRIBUTING](CONTRIBUTING.md). |
| Can I publish a free fork? | **Yes**, with credit: *Belay by PerfectoWeb*, linked back here. |
| Can I sell Belay? | **No.** |
| Can I sell a renamed Belay fork? | **No.** Not the app, not a derivative, not paid access to either. |
| Can I charge for my time helping someone use or modify it? | **Yes** – consulting and support are your work, not the software. |
| Is Belay OSI open source? | **No – it is source available.** The Open Source Definition requires allowing resale, and Belay's licence deliberately forbids it. |
