belay

Stays awake while your agents work.

Belay is a macOS menu bar app. It holds your Mac awake while a local AI coding agent is actually working, and lets it sleep normally the rest of the time. It watches Claude Code, Codex, Gemini CLI and Cline.

Detection is entirely local. No account, no API key, no telemetry. Belay looks at the session files your agent already writes on your own Mac, and reads only enough of them to tell working from finished.

Download for macOS Source on GitHub

Requires macOS 14 or later. Apple silicon and Intel.
